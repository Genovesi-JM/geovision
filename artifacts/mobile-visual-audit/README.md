# GeoVision mobile visual audit

This folder records the Phase 61 responsive-layout review.

- `before/ios-iphone15pro-home.png` records the previously installed build.
- `before/*-actions-horizontal-filter.png` records the action filter before it
  was made responsive.
- `after/ios-compact-*.png` records all five primary destinations at 320 × 568.
- `after/android-standard-*.png` records all five primary destinations at
  412 × 915.
- `after/ios-iphone15pro-current.png` and `after/ios-iphonese-home.png` are
  captures from installed iOS Simulator builds, including system safe areas.
- `after/android-emulator-current.png` and
  `after/android-emulator-actions.png` are captures from the installed Android
  Emulator build, including Android status and gesture-navigation areas.

The capture set is generated by `mobile/test/visual_snapshot_test.dart`; the
device matrix and review rules are documented in `docs/MOBILE_VISUAL_QA.md`.
