# GeoVision agent instructions

Read [the Valle Baobab operating contract](valle-baobab-ai-ops/AGENTS.md) before working in this repository. For a GeoVision product task, also read [the GeoVision Builder role](valle-baobab-ai-ops/agents/06-geovision-builder.md). For infrastructure, integration, or quality work, read the corresponding role in `valle-baobab-ai-ops/agents/`.

Use an isolated branch and one scoped change per task. Run the relevant tests, open a pull request, and leave merging and production release to human review. Keep credentials out of files and keep staging and production data separate.
